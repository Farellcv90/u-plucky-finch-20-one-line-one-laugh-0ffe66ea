Entry for the [One Line, One Laugh](https://make.fun/bounty/u-plucky-finch-20-one-line-one-laugh-0ffe66ea) competition on make.fun — one funny line of text, at most 200 characters, judged pairwise by an AI judge.

## The line

> I told my plants I'd water them tomorrow. That was three funerals ago.

## How to run

```sh
python3 main.py
```

This validates the line (single line, 1–200 UTF-8 characters, not only whitespace) and writes it to `/output/entry.txt`.
